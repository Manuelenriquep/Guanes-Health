# Working Note: Restoration Protocol Model (v2 archive)

This file is preserved as an earlier draft of the restoration-model idea.

It reflects an older and more assertive framing of the same conceptual direction later revised in `protocolo_restauracion_reporte-v3.md`.

The content below should be read as an archived working note for the evolution of the prototype, not as a validated clinical or scientific document.

## Summary

Version 2 explored the same core idea later implemented in simplified Python form:

- a tumor state with acidic microenvironment and apoptotic resistance,
- a weak isolated immunotherapy path,
- a stronger combined intervention path,
- deterministic assertions over a small number of modeled variables.

## Why this archive remains

This file is kept for project history. It shows how the modeling language evolved from a more rhetorical style toward a narrower and more explicit computational framing.

For the current public-facing description of the restoration scenario, refer to `protocolo_restauracion_reporte-v3.md` and the implementation in `03_Motor_Oncologico/`.
